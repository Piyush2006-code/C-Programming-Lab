## How to Compile and Run

Make sure a C compiler such as GCC is installed.

1. Open a terminal in the folder containing the program.
2. Compile the file:

   ```bash
   gcc 01_basic_io.c -o basic_io
   ```

3. Run the program on Windows:

   ```bash
   .\basic_io.exe
   ```

Replace the filenames with the relevant experiment's filename when running another program.
